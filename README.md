# 绳驱动蛇形机械臂

绳驱动蛇形机械臂是一种新型机械臂，如图1所示。其具有高冗余、高适应性、尺寸小且灵活的特点。绳驱动蛇形机械臂的驱动器和受控器之间经由较长的绳缆传动，这使得驱动器可以分立于关节，机械臂的尺寸和重量可以明显降低，更适合狭长、复杂的工作区域。类蛇形机械臂是一种典型的使用绳缆驱动关节的机械臂。其拥有特殊的几何形状，具有灵活的特性，在狭小、复杂等特种工况中具有相当广泛的应用前景，例如救援、医疗、高端装配、工业探索和核设施检查等。

根据结构类型，类蛇形机械臂由两种：1)连续型，2)离散型。连续性机械臂的手臂由连续的结构组成，通常在分析和控制方面视为一个整体，具有较高的适应性，但其精度和刚度较低。相比之下，离散型机械臂由多个串联的驱动组件构成，每个组件可以视为刚体。其分析和控制方法类似于超冗余机械臂，具有更高的刚度和定位精度。

绳驱关节是绳驱动蛇形机械臂的核心组件，通常由3根1组或4根2组驱动绳索对关节的两个自由度进行驱动。由于绳驱关节结构复杂、建模困难，其运动学模型和动力学模型的建立和运用相比传统机械臂具有更高的挑战。

本项目将围绕相关科研任务，总结国内外相关研究经验，从零起步，搭建绳驱关节实验平台。项目包含结构设计、电气设计、运动学与动力学分析、开环控制与闭环控制等工作。
